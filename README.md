## 🖥️ Simulador de CPU em C

Simulador de uma CPU simples desenvolvido em C para a disciplina de **Arquitetura e Organização de Computadores**.

O projeto simula conceitos básicos de uma CPU baseada na arquitetura de Von Neumann, incluindo memória, registradores, conjunto de instruções e ciclo de execução.

### Conceitos aplicados

- Arquitetura de Von Neumann
- Memória principal
- Registradores
- Conjunto de instruções
- Busca, decodificação e execução
- Assembly
- Operações aritméticas e lógicas
- Fluxo de execução de uma CPU

O programa de exemplo realiza a soma de duas matrizes 3 × 3 armazenadas na memória simulada.

### Tecnologias

`C` `Assembly` `Arquitetura de Computadores`

🔗 **[Ver projeto no GitHub](https://github.com/GabrielMaiaDeFreitas/CPU-simulador)**
